# MP3 — ton iPod noir

Un lecteur de musique rétro-minimaliste pour iPhone. Tu ajoutes tes propres sons, tu fais tes playlists, tu navigues avec la molette.
Tout reste dans ton iPhone : rien n'est envoyé sur Internet.

## Installer (une seule fois)

1. Sur github.com, connecte-toi (`mathematicien100frontieres`), clique **+ → New repository**, nomme-le `mp3`, laisse **Public**, puis **Create repository**.
2. Clique **uploading an existing file**, glisse **tout le contenu du dossier dézippé** (les fichiers ET le dossier `icons`), puis **Commit changes**.
3. **Settings → Pages** : *Source* = **Deploy from a branch**, branche **main**, dossier **/ (root)**, **Save**.
4. Attends 1 à 2 minutes. L'adresse est : `https://mathematicien100frontieres.github.io/mp3/`
5. Ouvre-la dans **Safari** sur l'iPhone → bouton Partager → **Sur l'écran d'accueil**. Utilise ensuite toujours cette icône.

## Utiliser

- **Molette** : fais tourner ton doigt sur le cercle pour descendre/monter dans les listes.
- **Bouton du centre** : choisir. **MENU** : retour. **▶❚❚** : lecture/pause. **◀◀ ▶▶** : titre précédent/suivant (maintenus : reculer/avancer dans le titre).
- **Appui long sur le centre** : options d'un son (playlist, pochette, infos, supprimer).
- **Ajouter des sons** (menu) : choisis des fichiers (app Fichiers). La pochette est lue automatiquement ; sinon l'appli te propose d'en ajouter une.
- **Playlists → Nouvelle playlist…**, puis *Modifier…* : ajouter des titres, réorganiser, renommer, supprimer.

## Bon à savoir

- Les sons sont stockés dans l'iPhone (pas dans le dépôt GitHub). Si tu supprimes l'icône ou les données du site Safari, ils sont effacés.
- iOS ne permet pas à une appli web de régler le volume : utilise les boutons de l'iPhone.
- Formats : mp3, m4a, aac, wav (flac/ogg selon l'iPhone). Les infos (titre, artiste, pochette) sont lues dans les mp3 et m4a.
- Pour mettre à jour l'appli : remplace les fichiers dans le dépôt, puis ferme et rouvre l'appli deux fois.
